# Mindful AI Sandbox

A full-stack starter template for the **Mindful AI Coding** course. Includes a Next.js frontend, Express.js backend, DynamoDB single-table design, Terraform infrastructure, and mock authentication so you can develop locally with zero AWS dependency.

## Getting Started

1. Click the **"Use this template"** button at the top of this repository, then **"Create a new repository"**.
2. Set the owner to your own GitHub account, name it whatever you like, and set it to **Private**.
3. Clone your new repo locally:

```bash
git clone https://github.com/<your-username>/<your-repo-name>
cd <your-repo-name>
```

4. Follow the **[Setup Guide](docs/Setup%20Guide.md)** for complete installation and configuration instructions.
